# Nerd in the Forest — Agent Instructions

`nerdintheforest.com` is an outdoor trail and GIS dispatch atlas built with **Nuxt 3, Vue 3, MapLibre GL, and Tailwind CSS**.

---

## 1. System Integration

* **Data Authority**: Reads content from `basecamp-cms` via REST endpoints:
  * `/api/nitf_dispatches`: Expeditions, GPS track geometry, telemetry.
  * `/api/nitf_locations`: Shelters, hearths, summits, potable springs, and trailheads.
  * `/api/nitf_gear_items` & `/api/nitf_loadouts`: Equipment locker and field kits.
* **Internal Docker Endpoint**: In production, server-side data fetching calls `http://basecamp:3000/api` via the `CMS_API_INTERNAL` environment variable.
* **Client Map Visualization**: Uses MapLibre GL to render topographic trail lines directly from GeoJSON `trail_geometry` generated by the CMS GPX ingestion hook.

---

## 2. Key Directories

* `pages/index.vue`: Interactive map atlas with dispatch inspection drawer and location filtering.
* `pages/gear.vue`: Dual-mode equipment locker and field loadouts browser with category weight telemetry.
* `components/`: Map controls, waypoint markers, elevation profile widgets, and dispatch cards.
* `composables/`: State management for active dispatch inspection, map viewport, and locker filters.

---

## 3. Development & Build

```bash
# Start local dev server (port 3003)
npm run dev

# Run Vitest test suite
npm run test:run

# Build production Nuxt output
npm run build
```
Docker container is served with `node .output/server/index.mjs` on port 3000.
